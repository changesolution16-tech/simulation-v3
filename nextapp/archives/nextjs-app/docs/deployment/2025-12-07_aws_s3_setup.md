# AWS S3 Setup Guide

## Complete S3 Configuration for Video & Image Storage

### Prerequisites

- AWS Account with admin access
- AWS CLI installed and configured
- IAM user with S3 permissions

## Step 1: Create S3 Bucket

### Using AWS Console

1. Go to https://console.aws.amazon.com/s3/
2. Click **Create bucket**
3. **Bucket name**: `soft-skills-videos` (must be globally unique)
4. **Region**: `us-east-2` (Ohio) - Same as your RDS
5. **Block Public Access**: Uncheck "Block all public access"
   - ⚠️ Warning will appear - confirm you understand
6. **Versioning**: Enable (recommended)
7. Click **Create bucket**

### Using AWS CLI

```bash
aws s3 mb s3://soft-skills-videos --region us-east-2
```

## Step 2: Configure Bucket Policy

This allows public read access to uploaded files.

### Create policy file: `s3-bucket-policy.json`

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::soft-skills-videos/*"
    }
  ]
}
```

### Apply the policy

```bash
aws s3api put-bucket-policy \
  --bucket soft-skills-videos \
  --policy file://s3-bucket-policy.json
```

## Step 3: Configure CORS

Allows your Next.js app to upload files directly to S3.

### Create CORS file: `s3-cors-config.json`

```json
{
  "CORSRules": [
    {
      "AllowedOrigins": [
        "http://localhost:3000",
        "https://yourdomain.com",
        "https://*.vercel.app"
      ],
      "AllowedMethods": ["GET", "PUT", "POST", "DELETE", "HEAD"],
      "AllowedHeaders": ["*"],
      "ExposeHeaders": ["ETag", "x-amz-server-side-encryption"],
      "MaxAgeSeconds": 3000
    }
  ]
}
```

### Apply CORS configuration

```bash
aws s3api put-bucket-cors \
  --bucket soft-skills-videos \
  --cors-configuration file://s3-cors-config.json
```

## Step 4: Create IAM User for Application

### Using AWS Console

1. Go to **IAM Console** → **Users** → **Add users**
2. **User name**: `soft-skills-app-user`
3. **Access type**: Programmatic access
4. **Permissions**: Attach existing policies:
   - `AmazonS3FullAccess` (or create custom policy below)
5. Save **Access Key ID** and **Secret Access Key**

### Custom IAM Policy (More Secure)

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "s3:PutObject",
        "s3:GetObject",
        "s3:DeleteObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::soft-skills-videos",
        "arn:aws:s3:::soft-skills-videos/*"
      ]
    }
  ]
}
```

## Usage Examples

### Upload Video File

```typescript
import { uploadFile, generateVideoKey } from '@/lib/s3';

async function handleVideoUpload(file: File, userId: string) {
  const buffer = Buffer.from(await file.arrayBuffer());
  const key = generateVideoKey(userId, file.name);
  const url = await uploadFile(buffer, key, file.type);

  console.log('Video uploaded:', url);
  return url;
}
```

### Generate Presigned Upload URL

```typescript
import { getSignedUploadUrl } from '@/lib/s3';

// Generate URL that client can use to upload directly
const uploadUrl = await getSignedUploadUrl(
  'videos/user123/my-video.mp4',
  'video/mp4',
  3600 // expires in 1 hour
);

// Client can now PUT to this URL
fetch(uploadUrl, {
  method: 'PUT',
  body: videoFile,
  headers: {
    'Content-Type': 'video/mp4',
  },
});
```

### Delete File

```typescript
import { deleteFile } from '@/lib/s3';

await deleteFile('videos/user123/old-video.mp4');
```

## Security Best Practices

### 1. Use Signed URLs for Uploads

Instead of uploading through your server, generate signed URLs:

```typescript
// API Route: /api/s3/presigned-url
import { getSignedUploadUrl } from '@/lib/s3';
import { getServerSession } from 'next-auth';

export async function POST(request: Request) {
  const session = await getServerSession(authOptions);
  if (!session) return Response.json({ error: 'Unauthorized' }, { status: 401 });

  const { fileName, fileType } = await request.json();
  const key = generateVideoKey(session.user.id, fileName);

  const uploadUrl = await getSignedUploadUrl(key, fileType);

  return Response.json({ uploadUrl, fileUrl: `${process.env.AWS_S3_PUBLIC_URL}/${key}` });
}
```

### 2. Implement File Size Limits

```typescript
const MAX_FILE_SIZE = 100 * 1024 * 1024; // 100MB

if (file.size > MAX_FILE_SIZE) {
  throw new Error('File too large');
}
```

### 3. Validate File Types

```typescript
const ALLOWED_VIDEO_TYPES = ['video/mp4', 'video/webm', 'video/quicktime'];
const ALLOWED_IMAGE_TYPES = ['image/jpeg', 'image/png', 'image/webp'];

if (!ALLOWED_VIDEO_TYPES.includes(file.type)) {
  throw new Error('Invalid file type');
}
```

### 4. Scan for Malware

Consider using:
- **AWS CloudWatch** for monitoring uploads
- **Third-party malware scanning** (e.g., ClamAV)

### 5. Use S3 Lifecycle Policies

Automatically delete old files:

```json
{
  "Rules": [
    {
      "Id": "DeleteOldTempFiles",
      "Status": "Enabled",
      "Prefix": "temp/",
      "Expiration": {
        "Days": 7
      }
    }
  ]
}
```

Apply with:

```bash
aws s3api put-bucket-lifecycle-configuration \
  --bucket soft-skills-videos \
  --lifecycle-configuration file://lifecycle.json
```

## Cost Optimization

### Storage Costs (us-east-2)

- **Standard Storage**: $0.023 per GB/month
- **Intelligent-Tiering**: $0.0025 per 1,000 objects + storage

### Data Transfer Costs

- **Upload to S3**: Free
- **Download from S3**: $0.09 per GB (first 10 TB)

### Recommendations

1. **Use CloudFront CDN**: Reduces data transfer costs
2. **Enable Intelligent-Tiering**: Auto-moves infrequently accessed files
3. **Compress videos**: Use H.264 codec for optimal size
4. **Delete unused files**: Implement cleanup job

## CloudFront CDN Setup (Optional but Recommended)

### Benefits
- Faster global delivery
- Reduced S3 data transfer costs
- Better user experience

### Setup

1. Go to **CloudFront Console**
2. Create distribution
3. **Origin domain**: `soft-skills-videos.s3.us-east-2.amazonaws.com`
4. **Origin path**: Leave empty
5. **Viewer protocol policy**: Redirect HTTP to HTTPS
6. **Allowed HTTP Methods**: GET, HEAD, OPTIONS
7. Create distribution

Update environment variable:

```env
AWS_S3_PUBLIC_URL=https://d1234567890.cloudfront.net
```

```json
          "Status": "Enabled",
          "Time": { "Minutes": 15 }
        }
      }
    }

```

## Troubleshooting

### CORS Errors

**Error**: "No 'Access-Control-Allow-Origin' header"

**Solution**:
1. Verify CORS configuration is applied
2. Check allowed origins include your domain
3. Clear browser cache

### 403 Forbidden

**Error**: Access Denied

**Solutions**:
1. Check bucket policy allows public read
2. Verify IAM user has permissions
3. Check object ACL

### Slow Uploads

**Solutions**:
1. Use multipart upload for large files
2. Implement CloudFront for global users
3. Consider S3 Transfer Acceleration
