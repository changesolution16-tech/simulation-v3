     tar -xzf soft-skills-training-migration-package.tar.gz
     cd migration-package

  2. READ DOCUMENTATION
     Start with: README.md or QUICK_START.md

  3. SETUP SUPABASE (10 minutes)
     - Create account at supabase.com
     - New project → Get credentials
     - Run database/complete-schema.sql in SQL Editor
     - Create admin user

  4. DEPLOY APPLICATION (15 minutes)
     - Extract source-code.tar.gz
     - npm install
     - Configure .env file
     - npm run build
     - Deploy to Netlify/Vercel

  5. TEST (5 minutes)
     - Login as admin
     - Create test simulation
     - Verify functionality

  TOTAL TIME: 30-40 minutes
