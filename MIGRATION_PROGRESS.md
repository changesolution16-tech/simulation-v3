## 🔧 Technical Architecture

### Data Flow
```
Component → React Query Hook → API Route → Database → Response
           ↓
         Cache (60s stale time)
```

### Component Pattern
```typescript
'use client';

import { useSimulations } from '@/hooks/useSimulations';

export default function MyComponent() {
  const { data, isLoading, error } = useSimulations();

  if (isLoading) return <SkeletonLoader />;
  if (error) return <ErrorMessage />;

  return <div>{/* render data */}</div>;
}
```

### API Route Pattern
```typescript
import { getServerSession } from 'next-auth';
import { db } from '@/lib/db';

export async function GET(request: Request) {
  const session = await getServerSession();
  if (!session) return new Response('Unauthorized', { status: 401 });

  const data = await db`SELECT * FROM table`;
  return Response.json(data);
}
```

## 📝 Key Decisions Made

1. **State Management:** React Query (not Zustand)
   - Better caching and loading states
   - Automatic refetching
   - Optimistic updates support

2. **Data Fetching:** Custom hooks wrapping React Query
   - Type-safe
   - Reusable across components
   - Centralized error handling

3. **Component Architecture:** Next.js App Router patterns
   - 'use client' for interactive components
   - Server Components where possible
   - API routes for all data access

4. **Styling:** Tailwind CSS + Dark mode
   - Consistent with Vite app
   - Responsive design
   - Accessibility-first
